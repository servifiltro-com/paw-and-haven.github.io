## Shopping Features

Visitors can browse products, search the catalog, filter by category, sort by price or name, open product details, add items to the cart, change quantities, remove products and save favorites.

The cart and wishlist are stored locally in the browser for this front-end demo.

Checkout is intentionally a demo flow and can later be connected to a real payment provider.

## Visual Direction

The store uses warm neutral tones, natural pet photography, rounded cards, clean product framing and a premium editorial layout.
