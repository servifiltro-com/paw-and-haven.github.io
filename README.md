# PAW & HAVEN

A polished pet-supplies storefront inspired by the clear category navigation, product-first shopping experience and simple commerce structure of modern pet retailers.

## V4 direction
- Category-led navigation for dogs, cats, outdoor, feeding, grooming and travel.
- Large lifestyle hero with clear shopping actions.
- Dedicated category cards with one image per category.
- Two editorial promotional banners.
- Structured product catalog with one image asset per product card.
- Search, filters, sorting, wishlist and cart interactions.
- Support form, FAQ and newsletter.
- Responsive mobile navigation.

## Technologies
HTML5 · CSS3 · JavaScript · LocalStorage
